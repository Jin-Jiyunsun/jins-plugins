# Tab Keybind Display

<img width="966" height="922" alt="keybind tab display image" src="https://github.com/user-attachments/assets/8ba8e160-1b5d-4b6a-bf6b-1beb92df4abd" />

Shows the keybind for each interface tab directly on the tab itself, so you can
see at a glance which key opens Inventory, Prayer, Combat, etc. This is useful
if you are learning your tab keybinds or if you just find a visual reminder
helpful! Works in all modes, both modern and classic resizable as well as fixed.

## Features

- **No setup needed**: Keybinds are read from your in-game controls and update
  automatically whenever you change them.
- **Key Remapping aware**: If you use RuneLite's Key Remapping plugin, tabs show
  the key set in that plugin rather than the original key.
- **Readable key names**: Longer names are shortened to fit the tab, such as
  `Backspace` to `Bksp`, `Page Up` to `Pg Up`, `Delete` to `Del` and
  `Escape` to `Esc`.

## Settings

All 14 tabs have their own section in the plugin's config panel:

- **Colour**: Set the colour globally for every tab, or a different colour
  per tab.
- **Position**: Set it globally for all tabs, or per tab. You can choose any
  corner of the tab, the centre or a custom offset. Text is always kept inside
  the corresponding tab, so it won't spill over into other tabs.
- **Text case**: You can choose if you'd prefer Standard Capitalisation,
  UPPERCASE or lowercase, depending on which is easier for you to read at
  a glance.
