# Keybind Tile Highlight

Highlights the game tile under your mouse cursor while a hotkey is held down.

The highlight follows the cursor — move to another tile with the key still held and the
highlight moves with it. Release the key and it disappears. Nothing is saved: no tiles are
marked, and no state persists between sessions.

## Setup

The hotkey is **unbound by default**, so nothing will happen until you set one:

1. Enable **Keybind Tile Highlight** in the plugin list.
2. Open its settings and set **Highlight key** to the key you want to hold.
3. Optionally change **Highlight colour**.

## Looking for persistent tile markers?

This plugin deliberately does not save anything. RuneLite's built-in **Ground Markers**
plugin (shift + right-click a tile) covers marking tiles permanently, with labels, colours
and minimap support.
